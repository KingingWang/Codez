### 状态与事件顺序

```text
正常：打开面板 → Host 读目录成功 → UI 展示引用数 → 用户确认 → Codex 配置写入
失败：打开面板 → Host 目录读取失败 → UI 展示未知 → 删除禁用 → 重新打开后重读
竞态：窗口 A 读到 0 → 窗口 B 写入模型引用 → 窗口 A 仍看到 0 → 窗口 A 删除
```

目录文件与 Codex 配置存在独立写入者，因此最后一个序列不是增加一次 UI
读取就能严格保证消失的。不能把 UI 投影提升为权威状态。
