# Draft suggested prompts

只提供当前静态建议语料及按模式、职业筛选的纯候选池。草稿、模式设置、职业资料和消息提交仍由原 owner 管理；本模块不读取服务、不加载插件、不提交消息、不保存轮换状态或第二份配置。

Feature 与 Office 入口分别保留现有筛选规则和本地化内容。候选中的图标、插件引用及导航提示是描述数据，不代表安装或执行许可；消费方继续走当前草稿与导航端口，不得修改导出的语料数组。

metadata 目录为首 root，`featureSuggestedPrompts.ts` 和 `officeSuggestedPrompts.ts` 是两个精确兼容公开入口。既有 V4 UI 和轮换控制器的位置、调用及行为不变。
