# Codex 能力 UI

Host hello 是能力事实来源，历史来自原只读 history port。hooks 只保留与当前
service/workspace scope 绑定的投影；旧 Host、缺失字段或探测失败按既有 fail-closed 门禁。
服务换代、运行时重启和卸载撤销旧结果资格，不从 MCP 状态猜测原生能力。

auto-review、file rewind、feedback、native host 和 auxiliary text 复用现有 hello。
feedback 的 native 门禁覆盖 Desktop 与 native 手机（含探测 pending），不是设备类型
开关；unsupported 不传消息反馈 handler，非 native Web/Codez 仍使用原有命令。
不启动另一运行时、不修改批准策略、不创建 read-cache 或新的重试 owner。
跨模块 UI 只经 contract 使用已有服务类型；受控公开入口保留原 helper/hook 路径。
